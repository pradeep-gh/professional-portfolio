AI-assisted engineering

Engineering with Claude Code

I use Claude Code as part of my daily development workflow. I set up the context, rules and checks first, so the AI works inside my architecture instead of guessing at it.

Project context

Each project has a CLAUDE.md file that records the architecture, package structure, coding standards, build and test commands, and the decisions the AI must not change.

Plan, then build

I agree a plan and the design first, then build in small steps. This keeps changes reviewable and keeps the code consistent with the service boundaries.

Repeatable workflows

Recurring tasks such as scaffolding a Spring Boot service, adding an endpoint, writing tests and preparing a pull request follow defined steps, so results don't depend on how I phrase a request that day.

Human in control

Tests and CI are the gate, and I review every change as I would a teammate's pull request. Design decisions and anything security-related stay with me.
